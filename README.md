# Facebook Mini 📱

A social media web application built with Flask and MySQL.

## Features
- User registration and login
- Post images to public feed
- Like and unlike posts
- Comment on posts
- Send/accept/delete friend requests
- Notifications system
- User profiles with photo upload
- Search users by name
- Delete your own posts
- Photos section per user

## Tech Stack
- Backend: Python, Flask
- Database: MySQL
- Frontend: HTML, CSS
- Deployment: Railway
